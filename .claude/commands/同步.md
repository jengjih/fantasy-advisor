description: 依使用者貼上的 Yahoo 截圖，同步 data/state.json 的陣容與對戰比分
---

使用者貼了 Yahoo Fantasy 截圖（My Team、Matchup 或 FA 名單）。請：

1. 判斷是哪個聯盟：8 隊、有 FGM 和 3PT% 欄位＝誰是懂球帝（程式裡的 key 是「聯盟一」）；12 隊、9 項＝baek's Grand League（key 是「聯盟二」）。看不出來就問。
2. 讀 `data/state.json`，跟截圖比對：
   - My Team：同步 roster 與 il（球員名字用 NBA 官方拼法，例如 Nickeil Alexander-Walker，不是 N. Alexander-Walker）。
   - Matchup：用 `fantasy_advisor.state.save_matchup()` 記錄週次、對手、各比項（字串照抄）、已用 adds，以及雙方本週剩餘出賽人次（Matchup 頁「Games Played 已打/總數」相減 → my_games_left、opp_games_left，看不到就填 -1）。
   - 對手陣容（Matchup 頁點對手隊名，或對手的 Team 頁）：用 `save_opponent_roster(label, 對手隊名, [球員…])` 記錄（不含 IL），用來預測結算比數。
   - FA 名單：用 `save_free_agents()` 記下綠色 +（純 FA）且不是 O 的球員（W 不算），推播 48 小時內只從這份名單推薦；再依該聯盟戰術推薦人選。
3. 修改請用 `fantasy_advisor.state` 裡的函式（apply_roster_changes、save_matchup），用 `uv run python` 執行（Mac 上找不到 uv 就用 `~/.local/bin/uv`）。
4. 查傷病：`fetch_injuries()` 抓 ESPN 即時傷病，列出雙方陣容（含對手）掛 Out／Day-To-Day 的人、預計回歸日；要簽的人也要確認沒有傷病。
5. 執行 `uv run python plan.py`（或 `--league 聯盟一`）：依賽程列出每天出賽／空位、預測結算比數、Adds 規劃（哪天、放誰、簽誰、淨多幾場），
   最後有「🎲 勝率模擬」：不換人、照 Adds 規劃換人兩種情況下本週贏的機率與各搖擺項的機率。
   以它的結果為基礎給建議；Yahoo 的「Games Played」剩餘數只算目前先發，不要拿來當剩餘場次。
   規劃器只看本週，回報時補上判斷（例如快回歸的傷兵、下週賽程、不要為了一場釋出潛力新秀）。
   想比較別的換法時，可以用 `projection.simulate()` 試算不同陣容的勝率。
   換人時間要注意：Daily-Today 聯盟，被釋出的人當天如果還有比賽，要等那場打完再換（用台北時間告訴使用者最早、最晚幾點）。baek's Grand League 週一到週四比分很接近時，可以加 `--allow-weekday` 試算。
6. 更新 `data/advisor_notes.md`：本週已做的換人、計劃、交易決定。
7. 改完後執行 `uv run python sync.py`，把資料推上 GitHub 的 main（網頁、16:00 和 22:00 的推播要用）。
8. 用白話中文回報：改了什麼、今天該做什麼（排陣、簽人，附台北時間）、哪些比項是搖擺項、本週贏的機率。
9. 回報文字全部寫完後，最後一步用 PushNotification 推手機通知（一行結論）。
